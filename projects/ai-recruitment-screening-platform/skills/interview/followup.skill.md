# Follow-Up Skill

Capacidad para hacer una repregunta breve cuando una respuesta no alcanza para continuar.

Reglas:

- Hacer una sola repregunta.
- Mantener la pregunta laboral y específica.
- No insistir si la persona no quiere responder.
- Redirigir si aparece información sensible.

Ejemplo:

"Para entenderlo mejor, ¿qué tarea concreta realizabas en ese proyecto?"
