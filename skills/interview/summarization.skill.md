# Summarization Skill

Capacidad para generar un resumen neutral para revisión humana.

El resumen debe incluir:

- Perfil laboral declarado.
- Experiencia relevante declarada.
- Herramientas, tecnologías o tareas mencionadas.
- Disponibilidad o modalidad preferida si fue informada.
- Puntos pendientes para que una persona profundice.

El resumen no debe:

- Puntuar.
- Aprobar o rechazar.
- Inferir datos no declarados.
- Usar datos sensibles.
